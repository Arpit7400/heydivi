# Put your song here 🎵 (optional)

Drop an `.mp3` file into this folder and name it **`song.mp3`**.
It will start playing when Divya taps "Begin", with a mute button in the top-right.

If you name it something else, update the `song:` line in `js/main.js`:

```js
song: "audio/your-filename.mp3",
```

No song? No problem — the mute button simply hides itself and everything else works.

(This file just keeps the folder in place. You can delete it once you've added your song.)
