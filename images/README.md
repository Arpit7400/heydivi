# Put your photos here 📸

Drop your image files (`.jpg`, `.png`, etc.) into this folder, then list each one
in the `photos` array inside `js/main.js`. For example, if you add `beach.jpg` here:

```js
photos: [
  { src: "images/beach.jpg", caption: "Goa, sunburnt and happy", year: "2024" },
]
```

- Any number from 3 to 30 photos works.
- Portrait (tall) photos look best as polaroids.
- If a filename doesn't match, that card shows an elegant heart placeholder instead
  of a broken image — so nothing ever looks broken.

(This file just keeps the folder in place. You can delete it once you've added photos.)
